# Письма из поддержки на почту

Приложение само отправляет каждое сообщение пользователя в поддержку на почту разработчика.
Бесплатно, без сервера: письмо отправляет Google Apps Script с вашего Gmail.

## Подключение (один раз, ~5 минут)

1. Откройте https://script.google.com под своим Google-аккаунтом → «Новый проект».
2. Удалите всё в `Code.gs` и вставьте содержимое файла `support-mailer/Code.gs` из этой папки.
3. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение»:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
4. Нажмите «Развернуть», разрешите доступ к Gmail, скопируйте URL вида
   `https://script.google.com/macros/s/.../exec`.
5. В Firebase Realtime Database создайте узел:
   ```
   support_config
     emailWebhookUrl: "https://script.google.com/macros/s/.../exec"
   ```

Готово. Письма приходят на почту аккаунта, под которым развернут скрипт.
Отвечать пользователям — в приложении, вкладка «Тикеты 🛠️» (видна только суперадмину).

Если поменяете `TOKEN` в `Code.gs`, поменяйте и `SUPPORT_EMAIL_TOKEN` в `app/src/main/assets/index.html`.
